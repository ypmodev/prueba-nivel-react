
# 📚 Nombre del proyecto

Aplicación web desarrollada con React y TypeScript que permite visualizar un catálogo de libros y consultar la información detallada de cada uno mediante navegación entre páginas.

## 🚀 Tecnologías utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router

## ⚙️ Requisitos previos

- Node.js (versión 20.19+ o 22.12+).
- npm.

Puedes comprobar las versiones instaladas con:

```bash
node -v
npm -v
```

## 📦 Instalación

**1. Clonar el repositorio**

```bash
git clone https://github.com/ypmodev/prueba-nivel-react.git
```

**2. Entrar en la carpeta**

```bash
cd prueba-nivel-react
```

**3. Instalar dependencias**

```bash
npm install
```

**4. Iniciar el proyecto**

```bash
npm run dev
```

## ✨ Funcionalidades

- Visualización de un catálogo de libros mediante tarjetas.
- Consulta de información detallada de cada libro.
- Gestión de los datos mediante un servicio local.
- Navegación entre el listado y el detalle de los libros.
